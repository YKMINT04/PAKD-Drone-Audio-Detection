# PAKD 送审简洁结果核查包

本目录用于核查当前论文稿件中报告的实验结果，保留以下材料：

- 53 个经 SHA-256 去重并核验的模型权重；
- 11 个与论文 Table I–XI 对应的简洁结果 TXT；
- 中性编号权重清单、结果映射与文件完整性校验值。

## 目录说明

- `checkpoints/`：去重后的模型权重，建议通过 Git LFS 管理。
- `results/`：与稿件表格对应的派生结果记录，不作为原始训练日志表述。
- `docs/checkpoint_inventory.csv`：采用中性编号的权重文件清单与完整性校验值。
- `docs/checkpoint_experiment_mapping.txt`：中性编号权重与论文表格、实验名称的对应关系。
- `docs/result_mapping.csv`：论文表格与结果记录的对应关系。
- `MANIFEST.csv`、`SHA256SUMS.txt`：文件级完整性校验。

本简洁包不包含完整训练过程记录或代码；原始材料由作者本地留存。论文录用后将补充核心方法实现和数据访问说明，公开仓库将长期维护。

## 权重文件格式

本版本中的 `.pth` 是面向推理发布的纯模型 `state_dict`。文件保留全部可学习张量、BatchNorm 的 `running_mean`/`running_var` 以及其他推理所需缓冲区；不包含优化器状态、训练环境元数据或仅用于记录训练更新次数的计数缓冲区。保留张量均与已核查原权重逐张量一致。
